# Vizzie

Vizzie is a mapping and analytics studio connected to the world's open data. There's nothing to download, and you don't need a GIS specialist to build beautiful maps, charts, and data stories.

**Try it:** [www.vizzie.org](https://www.vizzie.org) · **Portal directory:**
[vizzie.org/portals](https://www.vizzie.org/portals/) · **Tutorials:**
[youtube.com/@Vizzie_org](https://www.youtube.com/@Vizzie_org)

Public datasets maintained here:

- [open-data-portal-registry](https://github.com/Vizzie-org/open-data-portal-registry) —
  every portal Vizzie connects to: platform, API type, licences, and the measured share
  of datasets with no declared licence (CC BY 4.0).
- [india-district-name-aliases](https://github.com/Vizzie-org/india-district-name-aliases) —
  86 verified aliases that lift Indian district name-joins from 85.9% to a measured
  99.5% against geoBoundaries ADM2 (ODbL).
